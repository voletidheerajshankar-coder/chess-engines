# Retrieval-Augmented (RA) Chess Engine Portfolio
Developed by **Voleti Dheeraj Shankar**

Welcome to my official open-source chess computing repository. This project showcases the implementation of an advanced, modern Chess Engine architecture utilizing Retrieval-Augmentation (RA) algorithms alongside traditional search constraints.

## 🛠️ Architecture Blueprint
- **Retrieval Engine Layer:** Designed to proactively scan external Polyglot chess opening books and grandmaster tournament data to immediately verify lines before initiating heavy hardware tree calculations.
- **Python-Chess Framework:** Native validation routines written to monitor board legality and handle FEN parsing dynamically.
- **Lichess API Pipeline:** Ready to run natively over live websockets as an automated chess entity bot.

## 🚀 Dependencies & Execution
The application parameters are managed via standard configurations. Install all tracking dependencies directly using your CLI workspace:
```bash
pip install -r requirements.txt
```
